readme

Omarchy Retro 82 Theme

Retro-futurist Omarchy theme built from deep navy surfaces, warm amber focus states, and teal support colors. Retro 82 keeps the desktop dark and compact while carrying the same palette through the Quattro shell, terminals, editors, and application chrome.

Preview

Install

Use the Omarchy theme installer:

omarchy-theme-install https://github.com/OldJobobo/omarchy-retro-82-theme

What's Included

  • Native Omarchy 4/Quattro palette, Quickshell surfaces, and Hyprland Lua styling through colors.toml, shell.toml, and hyprland.lua
  • Omarchy 3.8 compatibility styling for Hyprland, Hyprlock, Waybar, Walker, Mako, and SwayOSD
  • A full Retro 82 Vencord skin in vencord.theme.css
  • VS Code integration for the standalone oldjobobo.retro-82-theme extension
  • Retro 82 terminal mappings for Alacritty, Foot, Ghostty, Kitty, and Warp
  • Editor and tool integrations for Neovim, Helix, Zed/Aether, Pi, Obsidian, btop, GTK, and Chromium

Wallpapers

The theme ships 27 still wallpapers plus two optional animated MP4 wallpapers for setups with animated-wallpaper support.
