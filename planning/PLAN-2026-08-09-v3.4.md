## §B — Patches applied in v3.4 (2026-08-09)

### B.1 — pipeline-deps.json: added 3 Q29c fields per layer

See `pipeline-deps.json` (project root). All 12 layers now carry:
- `id` — unique layer ID (e.g. "01_brief")
- `display_name` — human-readable name (e.g. "Brief")
- `depends_on` — list of prerequisite layer IDs
- `approval_required` — bool, true for layers needing explicit user approval
- `mmx_action` — which MiniMax action drives the layer (music.generate / image.generate / null)
- `output_table` — which SQLite table the layer writes to

`db/pipeline.py` continues to read `depends_on` only; the other 5 fields
are consumed by Day 4-7 handlers + Day 6 build runner.
