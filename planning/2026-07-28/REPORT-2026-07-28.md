## The actual blocker that "GO WITH ALL" fixed

The user said "i dont want open design in Claude Code. so you can uninstall and install again, ok?". The previous session ended with `byok-opencode: available: false` — the daemon's `executables.ts:resolveOnPath` only walks PATH looking for `.EXE/.CMD/.BAT`, but `opencode` was installed by npm as a `.ps1` PowerShell shim. **The 5-line `.cmd` shim I wrote is the single change that made everything downstream work.**
